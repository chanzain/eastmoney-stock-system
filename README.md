# 📊 板块竞价实时监控系统

基于东方财富 API 的 A 股板块竞价数据实时监控与历史回溯系统。支持行业板块、概念板块的竞价数据采集、实时监控、历史K线查询和成分股查看。

## ✨ 功能特性

### 实时监控
- **板块数据实时刷新**：行业板块（496个）和概念板块（486个）全量展示，支持 3s/5s/10s/30s 自动刷新
- **竞价数据采集**：在 9:15~9:30 集合竞价时段一键采集竞价快照，本地持久化存储
- **竞价额对比**：自动与前一日竞价数据进行对比，展示竞价额变化量与变化率
- **A股总数统计**：实时获取沪深A股+创业板+科创板股票总数

### 历史查询
- **历史K线数据**：通过东方财富 `push2his` API 获取任意交易日板块日K线数据
- **本地缓存**：首次查询后自动缓存，后续查询 <0.5s 响应
- **并发获取**：10线程并发获取全量板块K线，行业板块约5秒完成
- **日期选择器**：前端日历控件选择日期，已有数据日期自动提示

### 数据展示
- **多维排序**：涨跌幅、主力净流入、成交额、竞价额、换手率等多字段排序
- **板块详情弹窗**：点击板块行展示完整数据（价格、资金流向、竞价对比等）
- **成分股列表**：点击成分股数量查看板块内个股详情，支持分页浏览
- **交易状态指示**：自动识别竞价/交易/休市状态，界面实时反映
- **搜索过滤**：按板块名称或代码实时搜索

## 🚀 快速开始

### 环境要求

- Python 3.8+
- Windows / macOS / Linux

### 安装依赖

```bash
pip install flask waitress requests
```

### 启动服务

**方式一：命令行启动**
```bash
python server.py
```

**方式二：Windows 双击启动**
```
双击 start.bat
```

启动后浏览器访问 **http://localhost:8080**

### 竞价数据采集

在 **9:15~9:30** 集合竞价时段：

1. 点击页面上的「实时采集竞价数据」按钮
2. 系统自动采集所有板块的竞价快照
3. 数据保存到 `data/auction/` 目录

也可以通过命令行独立运行采集脚本：
```bash
python fetch_auction.py                    # 采集当前时间点数据
python fetch_auction.py --date 20260504    # 指定日期采集
```

## 📡 API 接口文档

### 板块数据

| 接口 | 方法 | 说明 | 参数 |
|------|------|------|------|
| `/api/sectors` | GET | 获取全量板块列表 | `type=industry\|concept` |
| `/api/sector-history` | GET | 按日期查询板块历史K线 | `date=YYYYMMDD`, `type=industry\|concept` |
| `/api/constituents` | GET | 获取板块成分股 | `code=BKxxxx`, `page=1`, `size=20` |
| `/api/stock-count` | GET | 获取A股股票总数 | - |

### 竞价采集

| 接口 | 方法 | 说明 | 参数 |
|------|------|------|------|
| `/api/fetch` | POST | 触发竞价数据采集 | `{"date":"", "time":""}` |
| `/api/fetch/status/<task_id>` | GET | 查询采集任务状态 | - |

### 快照数据

| 接口 | 方法 | 说明 | 参数 |
|------|------|------|------|
| `/api/snapshot/latest` | GET | 获取最新竞价快照 | `date=YYYYMMDD`（可选） |
| `/api/snapshot` | GET | 获取指定日期快照 | `date=YYYYMMDD` |
| `/api/dates` | GET | 列出所有有数据的日期 | - |

### API 响应示例

**获取板块列表：**
```bash
curl "http://localhost:8080/api/sectors?type=industry"
```

**查询历史K线数据：**
```bash
curl "http://localhost:8080/api/sector-history?date=20260430&type=industry"
```

**获取板块成分股：**
```bash
curl "http://localhost:8080/api/constituents?code=BK1305&page=1&size=20"
```

## 🔧 技术细节

### 为什么使用 Waitress 而非 Flask 开发服务器？

Windows 环境下 Flask 开发服务器（Werkzeug）与 Python `urllib.request` 存在兼容性冲突——在 Flask 请求处理线程中调用 `urlopen()` 会导致 HTTPS 连接超时卡死。使用 Waitress（生产级 WSGI 服务器）替代后，`urllib.request` 完全正常工作。

### 历史数据获取原理

1. 东方财富实时 API（`push2`）只返回当天数据，不支持历史日期查询
2. 历史数据通过 K 线 API（`push2his`）获取，传入目标日期参数获取该日的日K数据
3. 日K数据包含收盘价、涨跌幅、成交额等核心字段，但不含资金流向、领涨股等实时指标
4. 首次查询后缓存到 `data/history/` 目录，后续查询直接读取本地文件

### 并发策略

- 板块列表获取：循环分页（每页500条），串行请求
- K线数据获取：`ThreadPoolExecutor` 10线程并发，单次超时20秒
- 请求重试：`_em_get()` 最多重试2次，递增等待间隔

## ⚠️ 注意事项

1. **竞价时段限制**：竞价额数据仅在 9:15~9:30 集合竞价时段有意义，非竞价时段采集的 f6 为全天成交额
2. **API 频率**：自动刷新建议不低于 3 秒间隔，避免被东方财富限流
3. **数据缓存**：历史K线数据缓存后不会自动更新，如需重新获取请删除 `data/history/` 下对应的 JSON 文件
